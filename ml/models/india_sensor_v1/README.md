# National India B research bundle

**Confidential: do not publish before IP review. NOT HARDWARE VALIDATED.**

Three bounded XGBoost UBJ measurement-threshold heads, trained only on approved Indian NOAA data. No executable pickle, PM head, China data or disaster model. SHA256, ordered features, fit bounds, validation cutoffs, calibration and dataset/config provenance are in metadata.json. Paths to original input data are historical receipts; raw data is unnecessary for inference. Use the commands in [pipeline README](../../india_sensor/README.md). C/D in this bundle can only fall back to national B; A/regional models need a local full fit.

[Measured results and limitations](../../../reports/offline_phase/REPORT.md). Research flags are not field alerts. National wind probability is deliberately null because calibration is unsupported.
