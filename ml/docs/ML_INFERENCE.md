## Data Structures

### Tree Node (`xgb_node_t`)

```c
typedef struct {
    int8_t  feature_idx;   // -1 = leaf
    float   threshold;     // split threshold
    int16_t left_child;    // index of left child
    int16_t right_child;   // index of right child
    float   leaf_value;    // valid only if feature_idx == -1
} xgb_node_t;
```

### Tree (`xgb_tree_t`)

```c
typedef struct {
    uint8_t num_nodes;
    xgb_node_t nodes[MAX_NODES_PER_TREE];
} xgb_tree_t;
```

### Tree Arrays (per class)

## Normalization (Z-Score)

```c
// In normalization.h
static const float NORM_MEAN[NUM_FEATURES] = { ... };
static const float NORM_STD[NUM_FEATURES]  = { ... };

static inline void normalize_features(float *features, int num_features) {
    for (int i = 0; i < num_features && i < NUM_FEATURES; i++) {
        features[i] = (features[i] - NORM_MEAN[i]) / NORM_STD[i];
    }
}
```

**Must match training data statistics exactly.**

### Low-Level (from `model_data.h`)

```c
float xgb_tree_inference(const xgb_tree_t *tree, const float *features);

void xgb_model_inference(
    const float *features_raw,
```

### Firmware Wrapper (`ml.h` / `ml.c`)

```c
// Initialize — validates model constants
esp_err_t ml_init(void);

// Z-score normalize raw features (in-place or copy)

// Convert raw model output (log-odds) to probability [0,1]

// Diagnostics
```

## Usage Example (in `sensor_ml_task`)

```c
float raw_features[ML_FEATURE_COUNT];
float norm_features[ML_FEATURE_COUNT];

// 1. Populate raw features from sensors
raw_features[0] = reading.temperature;
raw_features[1] = reading.humidity;
// ... etc.

// 2. Normalize
ml_normalize(raw_features, norm_features);

// 3. Run inference for each class
for (int cls = 0; cls < NUM_HAZARD_CLASSES; cls++) {
    float raw_out;
    ml_predict(norm_features, cls, &raw_out);
    float confidence = ml_confidence(raw_out);

    if (confidence >= ALERT_THRESHOLDS[cls]) {
        queue_alert(cls, confidence, &reading);
    }
}
```
